# 🧰 Recommended Tools for Ransomware Defense

## 🔍 Detection & Monitoring
- CrowdStrike Falcon (EDR)
- Microsoft Defender for Endpoint
- Wireshark (packet inspection)

## 🔐 Backup & Recovery
- Veeam
- Acronis
- Snapshot-based NAS solutions

## 🛡️ Prevention
- Fortinet NGFW
- Cisco Umbrella
- Mimecast / Proofpoint (email filtering)

> Use in combination with incident response drills.
